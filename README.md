# museoprado

Web estática para una guía visual del Museo del Prado.

## Estructura

- `index.html`: página principal de **Isaac y Jacob**.
- `styles.css`: estilos compartidos.
- `script.js`: modal de infografía y botón de compartir.
- `images/`: imágenes usadas por la web.
- `audio/`: audios de la guía.
- `plantilla-cuadro.html`: base para crear otra página con el mismo estilo.

## Añadir otro cuadro

1. Duplica `plantilla-cuadro.html`.
2. Renombra el duplicado, por ejemplo `las-meninas.html`.
3. Añade la imagen nueva a `images/` y los audios a `audio/`.
4. Sustituye los textos marcados como `TODO`.
